# 🎗️ Breast Cancer Detection using CNN

## 📌 Project Overview
This project applies Deep Learning techniques to classify breast histopathology images into two categories:
- **Negative** (Benign/Healthy)
- **Cancer** (Malignant)

Using a Convolutional Neural Network (CNN) built with TensorFlow/Keras, the model analyzes tissue patterns to assist in medical diagnosis.

## 📂 Dataset
The dataset consists of histopathology images sourced from the [MachineLearnia Public Data](https://github.com/MachineLearnia/breast_cancer_public_data).
* The script automatically clones the dataset inside the notebook.
